# GreenMind AI

Identify plants from a photo, screen leaves for disease, and see *why* the model decided (Grad-CAM / Eigen-CAM).

Source code, experiments and paper: <https://github.com/mubashir20023/greenmind-ai>

This Space builds the app straight from the GitHub repository. Optional settings
(Settings → Variables and secrets): `SECRET_KEY`, `PLANT_ID_API_KEY`, `PLANTNET_API_KEY`,
`OPENWEATHER_API_KEY`, `OPENAI_API_KEY`, and `DATABASE_URL` for a permanent external database.
